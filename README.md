# House Lights

A small web app for controlling the LIFX lights on one house from an iPhone.

- Each person pastes their own LIFX personal access token (from cloud.lifx.com/settings).
- The token is stored only in that phone's browser and is sent only to api.lifx.com.
- A token can only control lights on its own LIFX account, so each house is fully independent.

Open the site in Safari, then Share → Add to Home Screen.
